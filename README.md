# M Plus y822

M PLUS 1p と Josefin Sans をベースにした、カスタムフォントです。

## 特徴
- **数字「2」の最適化**: Josefin Sans 特有のクセの強い「2」のデザインを、周囲の幾何学的な数字（3や5など）に馴染むよう美しく修正しました。
- **「I」と「l」の可読性バグの解消**: 大文字の「I」に美しいセリフ（ヒゲ）を持たせることで、小文字の「l」と一瞬で判別できるよう視認性を大幅に向上させています。
- ** その他: 制作者好みのデザインにいくつか変更しております。
